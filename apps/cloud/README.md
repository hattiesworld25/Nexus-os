# Nimbus Cloud

Run the root `README.md` setup first. Required variables are in `.env.example`.

```bash
npm install
npm test
npm run build
npm run dev
```

Verification: sign up; create folder; upload/download/share an allowed file; confirm image in Photos; create/save/trash/restore/purge a note and contact; add event and reminder; search; inspect Recent/Storage; sign in as a second account and verify it cannot see the first account's content. AI additionally requires `OPENAI_API_KEY` and `OPENAI_MODEL`.
